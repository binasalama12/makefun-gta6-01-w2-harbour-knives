HARBOUR OF KNIVES — Port Azahar Nights is an offline 3D heist adventure in raw WebGL, following Ren Vidal through six ledger jobs beneath Port Azahar’s rain-slick cranes and neon. CASE each target by reaching two scout points while staying outside the guards’ sweeping flashlight cones; STRIKE by snatching glowing ledger bags before the alarm or your carry limit forces the move; then ESCAPE with the take to the crew van or a marked hideout. Between jobs, sell the haul at the fence and choose one of three upgrade drafts, trading for deeper bags, quieter scouting, or a tougher getaway as the next night closes in.

## Run

Start the local game server from the repository root:

```sh
node serve.ts
```

To create the make.fun dossier in a chosen directory, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.
