HARBOUR OF KNIVES — Port Azahar Nights is an original offline 3D heist adventure rendered with raw WebGL. Take the wheel as Ren Vidal across five rain-drenched harbour districts, scout six targets, steal the ledgers, and evade the Port Wardens as the crew’s story plays out.

## Run

Start the local game server from the repository root:

```sh
node serve.ts
```

To create the make.fun dossier in a chosen directory, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.
