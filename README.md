HARBOUR OF KNIVES — Port Azahar Nights is an original, offline 3D open-world heist game built with raw WebGL. Drive Ren Vidal through five rain-soaked harbour districts, case six targets, strike for the ledgers, and outrun Port Wardens while your crew’s story unfolds.

## Run it

```sh
node serve.ts
```

Set an output directory and build the make.fun dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
