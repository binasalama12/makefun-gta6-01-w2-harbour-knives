HARBOUR OF KNIVES — Port Azahar Nights is an original offline 3D heist adventure rendered with raw WebGL, following Ren Vidal through six ledger heists across Port Azahar’s rain-soaked harbour. Work each job through CASE, slipping past guards and their searching flashlight cones; STRIKE, grabbing ledger bags before the alarm peaks; and ESCAPE, racing the take to the crew van or a hideout. Between jobs, fence the proceeds and choose one of three upgrade drafts to shape the next run, from deeper bags to quieter approaches and a stronger getaway.

## Run

Start the local game server from the repository root:

```sh
node serve.ts
```

To create the make.fun dossier in a chosen directory, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.
